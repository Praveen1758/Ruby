Welcome to my Ruby learning repository! This project tracks my progress as I master the fundamentals of the Ruby programming language, focusing on clean syntax, object-oriented programming (OOP), and practical scripting.

* Master core Ruby syntax, data types, and control structures.

## 🛠️ Getting Started

### Prerequisites
Make sure you have [Ruby installed](https://www.ruby-lang.org/en/documentation/installation/) on your machine. Check your version by running:
```bash
    ruby -v
```

### Running Scripts
Clone this repository and run any script using the Ruby interpreter:
```bash
git clone https://github.com
cd Ruby/assign_1.rb
ruby assign_1.rb
```
